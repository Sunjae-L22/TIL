# 집필과 시각자료

## 콘텐츠별 판단

- 강의 기반: 자료 순서를 따르기보다 선행 개념과 독자 질문을 기준으로 설명한다. 공개 가능한 1차 자료를 함께 연결한다.
- 논문리뷰: 문제·핵심 기여·수식/구조·실험 조건·한계를 보존한다. 원문 보고값과 자체 재현을 구분한다.
- 알고리즘: 정답 조건·불변식·복잡도·경계 입력을 설명한다. 실패 경험이 제공되지 않았으면 “처음에는 이렇게 틀렸다”는 1인칭을 만들지 않는다.
- 실용 정보: 실행 환경과 확인 날짜를 적고 공식 문서에 근거한다. 검색량·경쟁도·광고 단가를 근거 없이 수치화하지 않는다.

정해진 제목 형식·목차·문단 순서·이미지 수를 강요하지 않는다. 기본 문체는 자연스러운 -다체이며 “왜 필요한가”와 핵심 답을 초반에 드러낸다. 긴 글은 탐색 가능하게, 짧은 질문은 짧게 답한다. 검색어 반복 대신 제목과 본문이 같은 질문에 답하는지 본다.

## 시각자료 선택

각 이미지에는 설명 목적을 적는다. 과정·상태 변화·반례·비교에 도움이 될 때 만든다. 개수 하한과 분량 비례 할당량은 없다.

- 수치 차트: 실제 결과에서 표준 plotting 도구로 만든다.
- 알고리즘 그래프와 기술 도식: 편집 가능한 SVG/HTML로 만들고 공개용 PNG를 함께 보관한다. 화살표·수식·수치를 검증한다.
- 일러스트와 썸네일: 사용 가능한 ImageGen 도구를 쓴다. 정밀한 데이터 그래프를 이미지 생성 모델에 맡기지 않는다.
- 인터랙티브 도구: 설명상 이득이 있을 때 만든다. 본문만으로도 핵심을 이해할 수 있게 정적 대안을 제공한다. 티스토리 임베드 지원 또는 외부 호스팅 주소를 실제 확인하기 전에는 연결 완료로 쓰지 않는다.

작은 화면에서도 라벨이 읽히게 하고 한글 폰트를 확인한다. 본문 alt와 그림 설명을 유지한다. SVG 원본이 없는 사진을 오류로 보지 않는다. 브라우저 미리보기 통과와 티스토리 저장 후 표시 통과는 별개다.

## 공개 내용의 출처

논문과 공개 문서의 출처·저자를 보존한다. SSAFY 같은 기관명 자체를 자동으로 금지하지 않는다. 비공개 강의의 원본 파일·계정 정보·내부 주소·개인 경로를 공개 패키지에 넣지 않는다. 출처 익명화가 공개 허락을 대체하지 않는다. 정확한 원문 전사가 필요한 비공개 TIL과 재구성한 공개 글을 구분한다.
