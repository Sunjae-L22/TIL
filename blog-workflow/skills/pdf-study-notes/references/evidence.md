# 근거와 실험 기록

## 주장 구분

| 종류 | 기록할 내용 |
|---|---|
| source | 파일 SHA-256 또는 실제 URL, PDF 물리 페이지, 근거가 되는 표현 |
| correction | 원래 표현, 교정한 표현, 재현 결과 또는 공개 1차 출처 |
| inference | 근거가 되는 전제와 적용 범위, 아직 검증하지 않은 부분 |
| experiment | 실행 코드와 해시, 입력·시드·환경, 결과 파일, 본문에서 쓰는 수치 |

그럴듯한 참고문헌을 채워 넣지 않는다. 제목만 아는 논문은 원문을 확인하기 전까지 미확인으로 둔다. 벤치마크를 재현하지 못하면 원문 보고값으로 인용하고 재현했다고 쓰지 않는다.

## 학습 노트의 기본 형태

제목과 범위 → 개념을 묶은 설명 → 예제 및 경계 조건 → 원본 교정과 근거 → 복습 질문. 필요한 요소만 사용한다. 페이지 수에 비례한 분량 목표는 두지 않는다. 개념을 이해하는 데 중요한 그림은 텍스트 설명도 함께 남긴다.

원본 파일과 작업 상태는 비공개 작업 자료다. 공개 글에는 접근 가능한 출처와 자체 설명·실험을 사용한다. 기관명을 일괄 삭제하거나 출처를 감춘다고 공개 권한이 생기는 것은 아니다.

## 재현 완료의 의미

실행 종료 0만으로 주장 전체가 증명되는 것은 아니다. 무엇을 검사했는지와 검사하지 않은 일반화를 함께 적는다. 시간 측정에는 기기·언어 버전·반복 횟수·통계량을 기록한다. 반례는 입력과 기대 결과가 독립적으로 확인 가능해야 한다.
